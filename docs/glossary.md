# Glossary

## API

An API is a way for one software system to talk to another software system.

## API Key

An API key is a secret value that proves your app is allowed to use a service.

## Authentication

Authentication means proving who you are.

## Authorization

Authorization means deciding what an authenticated person or system is allowed to do.

## CLI

CLI means command-line interface. It is a tool you use by typing commands in a terminal.

## Corpus

A corpus is a collection of documents used for search or analysis.

## Chunk

A chunk is a small piece of a larger document.

## Database

A database stores data in an organized way. This project does not use a traditional database.

## Deployment

Deployment means running the app somewhere users can access it.

## Docker

Docker is a tool for running apps inside containers. This repository does not include Docker setup.

## Embedding

An embedding is a list of numbers that represents the meaning of text. Similar text gets similar numbers.

## Environment Variable

An environment variable is a named setting that an app reads when it starts.

## JSON

JSON is a common text format for structured data.

## JSONL

JSONL means JSON Lines. Each line is one JSON record.

## LLM

LLM means large language model. It is an AI model that reads and writes text.

## NERC

NERC means North American Electric Reliability Corporation.

## NIST

NIST means National Institute of Standards and Technology.

## CISA

CISA means Cybersecurity and Infrastructure Security Agency.

## DOE

DOE means Department of Energy.

## FERC

FERC means Federal Energy Regulatory Commission.

## OT

OT means operational technology. It includes systems that monitor or control physical equipment.

## ICS

ICS means industrial control system. It is a type of OT used in industrial environments.

## Pinecone

Pinecone is a hosted vector database. This project uses it for semantic search.

## RAG

RAG means retrieval-augmented generation. It means searching source documents before generating an answer.

## Repository

A repository is a project folder tracked by Git.

## SerpAPI

SerpAPI is a service that returns search engine results through an API.

## Streamlit

Streamlit is a Python tool for building browser apps.

## Vector

A vector is a list of numbers. In this project, vectors represent document meaning.

## Virtual Environment

A virtual environment is a private Python library folder for one project.
